Place all three kicad files (.kicad_pcb, .kicad_sch, .kicad_pro) in a folder of the same name. Open the project file (.kicad_pro) with KiCad.

A 3.5mm TRS audio jack passthrough to reroute signals in the monitor enclosure. The bottom jumpers on the PCB must be soldered if this PCB is being used as a straight audio passthrough only. The board also doubles as a ground loop isolator using not-so-great audio transofrmers. From my 'raw ear listening' testing, you can't tell how the cheap these parts are. The 65mm diameter speakers cannot output freq under 100Hz, which doesnt matter as the cheap audio transformers cannot pass anything below 200Hz. That sub 200Hz roll-off numbers might be a lie one the datasheet- the parts are so cheap.
