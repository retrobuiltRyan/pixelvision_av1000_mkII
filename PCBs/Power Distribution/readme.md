Place all three kicad files (.kicad_pcb, .kicad_sch, .kicad_pro) in a folder of the same name. Open the project file (.kicad_pro) with KiCad.

Handles input power distribution, power on/off switching, and power rerouting. Board includes two 5 V linear regulators and one adjustable buck converter.
